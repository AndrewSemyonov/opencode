## Security checks

Unknown component should render as a yellow placeholder, not crash:

<UnknownThing foo="bar" />

Non-literal expression in prop should be ignored with a console warn:

<KPI title="Risky" value={Date.now()} />

Raw HTML should be stripped:

<script>alert('xss')</script>

`javascript:` link should be neutralised:

[click me](javascript:alert(1))

Done.
